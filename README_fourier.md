# Simulación y análisis de señales con la Transformada de Fourier

Actividad formativa 2. Programa en Python para analizar un pulso rectangular, una función escalón y una señal senoidal mediante la Transformada Discreta de Fourier (FFT).

## Requisitos
- Python 3
- NumPy
- Matplotlib

## Instalación
```bash
pip install numpy matplotlib
```

## Ejecución
```bash
python simulacion_fourier.py
```

El programa grafica las señales en el dominio del tiempo, los espectros de magnitud y fase, y realiza comprobaciones de linealidad, desplazamiento temporal y escalamiento temporal.

## Archivos
- `simulacion_fourier.py`: código fuente comentado.
- `Actividad_Formativa_2_Transformada_Fourier.docx`: informe escrito con resultados y gráficas.
